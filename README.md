<h3 align="center">
The Evidence-Based, Gamified Quit Smoking Companion
</h3>

**UnSmoke** is an advanced Android application designed to help users quit smoking using behavioral support, cessation tracking, gamification and AI-powered guidance.

### 🧠 Core Features

* ⏱️ **Live Quit Timer** — tracks the exact smoke-free duration
* 🌊 **Craving Timer & Urge Surfing**
* 🧠 **4 D's Craving Toolkit**

  * Delay
  * Deep Breathe
  * Drink Water
  * Do Something Else
* 💊 **NRT Tracker** — track nicotine replacement therapy usage
* 💰 **Money Saved Calculator**
* 📊 **Recovery & Health Analytics**
* ❤️ **Health Connect Integration**
* 🤖 **AI Quit Coach powered by Gemini**
* 💧 **Vaping / E-Cigarette Cessation Mode**
* 👽 **Virtual Companion / Tamagotchi Gamification**
* ⌚ **Wear OS Companion App**
* 🔐 **Privacy-first local data storage**
* 🔒 **Biometric App Lock**

### 🛠️ Built With

```text
Kotlin
Jetpack Compose
Android
Room Database
Health Connect
Gemini AI
Wear OS
Jetpack Glance
DataStore
Material 3
```
